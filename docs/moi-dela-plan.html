Мои дела для iPhone, iPad и Apple TV

Нативное приложение SwiftUI на основе дашборда «Мои дела». Ниже: что уже сделано на шаге 1, из чего состоит приложение, как защищены данные и в каком порядке будем строить. Каждый шаг заканчивается проверкой.

Шаг 1: что сделано

готово
Создан проект MoiDela: одно приложение SwiftUI для iPhone, iPad и Apple TV, стартовый экран «Мои дела» с названием устройства.
готово
Проверен ваш Mac Studio: macOS 27.0.1, Xcode 27.0, Swift 6.4, платформы iOS 27 и tvOS 27. Command Line Tools входят в Xcode, отдельно ставить не нужно. Добавлен XcodeGen 2.46.

в работе

Приложение не ходит во внешние сервисы напрямую. Оно читает из своей базы и ставит действия в очередь. Серверная функция выполняет действие ключом из Vault и пишет результат обратно. Apple Reminders — исключение: это данные на самом устройстве, их модуль работает локально через EventKit.

Данные

В каждой таблице есть поле user_id, и на каждой стоит правило: строку видит и меняет только её владелец (user_id = auth.uid()). Это правило работает в самой базе, поэтому даже ошибка в приложении не покажет чужие данные.

ТаблицаЧто хранит
snapshotsНаборы от задач Claude целиком (JSON): report, joschka, body, replies, sales, liposts, digest, pfbrief, rest. Ключ: пользователь + набор + дата. Хранится история
itemsОтдельные дела, с которыми можно что-то сделать: задача, сообщение, пост, событие, упражнение. Источник, внешний id, статус
actionsОчередь действий: что сделать, с чем, статус (ждёт подтверждения → подтверждено → выполняется → готово или ошибка), кто и когда подтвердил
connectionsКакие сервисы подключены и с какими правами. Сами ключи лежат в Vault
user_modulesКакие модули включены, порядок на главном экране
ingest_tokensКлючи для задач Claude: в базе хранится только отпечаток ключа, ключ можно отозвать
audit_logЖурнал: кто, что и когда изменил или отправил

Безопасность

  • Вход. Sign in with Apple. Сессия Supabase хранится в Keychain с доступом «только это устройство, после первой разблокировки». Виджеты читают её через общую группу Keychain.
  • Face ID. Запрашивается при открытии и возврате в приложение через 5 минут. Ещё раз перед действиями наружу: отправить письмо или сообщение, создать событие.
  • Ключи внешних сервисов (Google, Slack, Asana, Pipedrive) не попадают на телефон. Они лежат в Supabase Vault, ими пользуются только серверные функции.
  • Публичный ключ Supabase в приложении не секрет: без входа он ничего не открывает, всё закрыто правилами доступа. Сервисный ключ хранится только на сервере, никогда в коде.
  • Копия данных на устройстве для офлайна и виджетов хранится с защитой файлов iOS: файл зашифрован, пока телефон не разблокирован.
  • Проверка правил. Автотесты заходят в базу под двумя разными пользователями и проверяют, что чужие строки не видны и не меняются.
  • Apple TV только показывает данные: кода действий в версии для TV нет.

Модули

Модуль — это пакет Swift с общим протоколом: название, иконка, какие данные читает, карточка для главного экрана, подробный экран, вид для TV, виджет (если есть) и список поддерживаемых действий. Приложение собирает главный экран из включённых модулей. Новый сервис — новый пакет, остальной код не меняется.

Как работают действия

  1. Вы нажимаете, например, «Отправить черновик». Приложение показывает текст и адресата целиком.
  2. Подтверждаете через Face ID. В очередь actions уходит запись со статусом «подтверждено».
  3. Серверная функция отправляет письмо через Gmail ключом из Vault, ставит «готово» или «ошибка» с причиной.
  4. Приложение показывает результат. Без вашего подтверждения письма, сообщения и события календаря не отправляются.

Простые отметки (галочка упражнения, «пост прокомментирован») подтверждения не требуют и работают офлайн: запись уйдёт, когда появится сеть.

Как задачи Claude будут писать в базу

Сейчас задачи Claude по расписанию пишут наборы в дашборд. Добавим точку приёма в Supabase (серверная функция ingest). Задача отправляет набор вместе со своим ключом; функция проверяет ключ и формат и записывает набор в snapshots, а дела из него — в items.

  • Переход без риска: какое-то время задачи пишут и в дашборд, и в базу. Дашборд отключим, когда приложение покажет всё.
  • Позже: собственный коннектор «Мои дела» для Claude со входом через ваш аккаунт, без отдельных ключей.
  • Отметки обратно: правила вроде «не терять sent у постов LinkedIn» переходят в базу. Отметку ставите вы в приложении, задача её не перезаписывает.

Аккаунт разработчика

Важно: на бесплатном личном Apple ID нельзя включить Sign in with Apple. Кроме того, приложение на iPhone перестаёт открываться через 7 дней и его нужно ставить заново из Xcode, а TestFlight недоступен.

Поэтому на этапе разработки вход будет по коду на e-mail (это Supabase тоже умеет). Sign in with Apple включим, когда появится аккаунт SDH IT GmbH. Код входа сделаем так, чтобы смена способа входа была заменой одного модуля.

Совет: начните регистрацию SDH IT GmbH в Apple Developer Program уже сейчас. Для компании нужен номер D-U-N-S, его выдача может занять до двух недель. Стоимость программы — 99 USD в год (в Германии около 99 €).
